# Archive

Review rounds, gate-run outputs, and working notes from CodeReview's own development, moved here from the repository root so the root stays readable. Nothing was deleted or edited. Some historical records mention these folders by their old root-level names.

The live data files (`dispositions.jsonl`, `gate-attempts.jsonl`, `gate-attempts.md`, `precedents.json`) stay at the repository root because the tool and its tests read them there.
